# Internship Completion Rate Analysis

## 📊 Internee.pk Internship - Task 01

This project was completed as part of my remote internship at Internee.pk.

The objective of this task was to analyze internship enrollment, completion, and dropout rates and identify key factors associated with successful internship completion.

## 🎯 Objectives

- Analyze internship enrollment and completion data
- Calculate completion and dropout rates
- Identify trends by department
- Analyze internship duration
- Analyze mentor interaction
- Create an interactive Power BI dashboard

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Microsoft Excel
- Data Visualization

## 📁 Dataset

The dataset contains 200 internship records with the following attributes:

- Intern ID
- Department
- Duration (Months)
- Mentor Meetings/Month
- Enrollment Date
- Completion Date
- Status

## 📈 Dashboard KPIs

- Total Enrollment: 200
- Completed: 163
- Dropped: 37
- Completion Rate: 81.5%
- Dropout Rate: 18.5%

## 📊 Dashboard Analysis

The dashboard provides analysis of:

1. Department-wise internship status
2. Overall completed vs dropped interns
3. Internship status by duration
4. Completion rate by mentor interaction
5. Interactive filtering using department and duration slicers

## 🔍 Key Insights

- The overall internship completion rate was 81.5%.
- 163 out of 200 interns completed their internships.
- 37 interns dropped out.
- Internship outcomes were analyzed across different departments and durations.
- Mentor interaction was analyzed as a potential factor associated with completion.
